# IBKR辅助交易系统行为契约

日期：2026-10-25。来源：用户在会话审阅完整设计后，明确要求更新GitHub文档及代码；据此授权保存、实施、测试和发布。本文件对应`docs/trading-system.md`的可执行部分。

## 边界

- 策略固定为`sma200-rolling20-guard-sgov-v1`。QQQ完整收盘计算包含当日的SMA200、20日最高收盘；均线防守优先于8%退出、入场和漂移控制。交易QQQ/TQQQ/SGOV，Decimal小数股。
- 初始保留现有持仓。默认SHADOW、UNINITIALIZED，不创建券商指令。实际迁移需确认资金范围、账户绑定、周期及旧单归属。不能按仓位比例推断BOOST资格。
- 程序不连接券商、不提交订单。读取规范JSON，生成精确的非约束指令参数。Codex连接器的外部调用须遵循持久化发布协议，真实订单由用户在IBKR确认。
- 不创建定时任务、改变账户权限、取消真实挂单或用聊天记忆代替数据库。

## 输入输出与副作用

CLI统一为`python -m trading_system --db PATH --input PATH COMMAND`；JSON金额和数量使用十进制字符串，时间必须含时区。状态查询不需要输入文件。

| 命令 | 行为 |
| --- | --- |
| initialize | 显式接纳策略持仓及现金；缺少迁移确认时保持UNINITIALIZED |
| evaluate | 校验完整交易日和200根日线，保存每日单一决策；无交易副作用 |
| prepare | 以最新快照和报价制定一笔SELL优先的DAY限价计划，或返回等待/阻断 |
| record-external | 记录发布开始、指令回执/缺失证明、真实订单绑定、资金及分红事件 |
| reconcile | 按真实成交幂等记账、更新订单终态、识别未完成目标；部分成交不完成整个转换 |
| status | 报告状态、目标、计划及能力缺口 |
| backup | 创建不可覆盖的私有一致性备份，恢复副本强制先对账 |

结果包含`status`、`reason`及适用的`decision`、`plan`、`payload`。退出码0含正常等待，2表示输入错误，3表示阻断，4表示外部发布结果未知。无HTTP接口，Apifox不适用。

## 不变量

1. 只有实际成交、已确认资金事件改变持仓/现金账本；信号和指令不改变。
2. 同一成交ID重复回报不重复记账；已存在成交字段发生变化时阻断。后到佣金通过累计费用差额更新。
3. 账户授权引用不符、数据失败/不完整、未知旧单、冻结/过时报价、无法确认报价时间时不生成可发布计划。
4. 发布开始先持久化；超时/崩溃后的PUBLISHING不自动重发。无券商客户端幂等键，不声称恰好一次。
5. 指令ID、订单ID、成交ID分别记录。链接不是唯一标识；订单绑定需要明确用户确认并核对参数。
6. 同一信号不能退出后重新入场；待完成退出优先保留。跨日不补演虚构成交。
7. 先卖后买，资金按策略现金和券商可用已结算美元的较小值约束；不使用购买力融资。
8. 预留max(20美元,可交易净值×2%)及已确认的费用预算。0.40美元研究假设不进入实盘费率。
9. 计划有效期、非约束指令保留期、真实订单DAY期限互相独立。过期指令需要外部查明，不能只删除本地记录。
10. 未知状态、不可对账、版本不符时关闭新增计划；数据库使用事务、单写入锁和恢复后对账。

未确认周期的SHADOW输入返回各状态的假设信号，不创建目标。迁移使用明确的migration_confirmation事件，保留已记资金事实。执行细节与初始参数见运行手册：最大1美元分配残差不豁免零目标风险资产清仓；费用预算最多六笔是资金上限，实际佣金单独记录。

## 场景与断言

| 场景 | 断言 |
| --- | --- |
| 入场等号/退出等号/70%等号 | 入场不触发，退出触发，70%不调 |
| 两种退出同时成立 | SGOV防守，不能转QQQ |
| BOOST超过70% | 不触发普通漂移控制 |
| 初始已有仓位 | 保留事实，未确认前不迁移 |
| 部分成交、重复回报、晚到费用 | 准确记账，剩余任务保留，费用只更新差额 |
| 指令创建超时/重启 | 返回UNKNOWN_PUBLICATION，不生成重复指令 |
| 冻结行情、未知订单、资金不足 | 阻断或等待，无外部下单副作用 |
| SGOV分配/入金 | 应收和可交易现金区分，事件幂等，不重置周期 |
| 节假日、半日市、夏令时 | 按XNYS交易日历，不按固定新加坡时间 |

验收采用unittest、CLI子进程、SQLite重开恢复和新包语句覆盖率≥80%。开市报价时间、指令到订单关联及真实账户迁移须实测；离线测试不能替代这些项目。
