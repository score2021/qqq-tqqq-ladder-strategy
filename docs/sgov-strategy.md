## 状态转换

| 当前状态 | 下一步 |
| --- | --- |
| QQQ | 满足E进普通60/40；触发均线防守则转SGOV；否则持QQQ |
| SGOV防守 | 满足E进入100% TQQQ周期；否则保持SGOV |
| 普通60/40 | 均线退出转SGOV、8%退出转QQQ、TQQQ超过70%时回60%目标 |
| 100% TQQQ周期 | 均线退出转SGOV，8%退出转QQQ；不因超过70%而减仓 |


先判断均线防守，再判断TQQQ移动退出，再判断满足E的新入场，最后判断普通混合仓漂移。每个完整收盘最多一个动作。

均线防守触发后即使后续恢复至SMA200附近，只要E未同时成立就继续SGOV；普通QQQ入场受阻继续QQQ。移动退出回QQQ后不继承100%恢复资格，后续只能普通60/40，直到新一轮均线防守和恢复。SGOV月度分配留现金，下次策略配置才使用，不自动复投或产生股票信号。

## 现金及费用示例

10,000美元账户预留200美元；普通QQQ转60/40时实际通常有卖QQQ、买TQQQ两单，共0.80美元，先从可投资预算扣这两笔费用，再分配60/40并按研究精度向下取整。均线全清普通混合仓转SGOV可能产生卖QQQ、卖TQQQ、买SGOV三单，共1.20美元。SGOV恢复全TQQQ通常两单共0.80美元。实际单数取决于非零持仓与目标差，不为零数量收费。

“100%”指现金预留和该批费用之后可投资部分，不借款。示例不能当作IBKR实际成交精度、费率或执行保证。费用逐次降低份额和后续分红/复利，并非末日扣一笔。

## 20日峰值含义

H20=max(Close[t-19],...,Close[t])，M=mean(Close[t-199],...,Close[t])。两窗口包含信号日，入场和退出都使用同一个H20。若旧高点离开窗口，H20和0.92阈值可下降；这不是买入以来只升不降的峰值，也不是账户8%硬止损。

## 历史可用性与状态标签

SGOV发行商成立日2020-05-26，本次缓存起于2020-06-01，之前均线防守持美元。成立到缓存首日之间本次各路径无防守需求；此前不持有不存在/没有数据的SGOV。2021起点全程有SGOV真实数据，实际三轮SGOV持有为2022-01-21→2023-01-30、2025-03-11→2025-05-13、2026-03-23→2026-04-09。
