## README 复现顺序

1. 全新下载仓库。
2. 按 README 安装 Python 依赖，运行 10 项合成测试。
3. 下载或提供完整行情 JSON，核对日期、缺失值、拆分和数据哈希。
4. 运行研究比较与概率实验；核对 `results/` 中的归档值及定义。
5. 老虎部分需用户自己的平台会话，核对首次回调、完整运行、订单终态及净值。此步骤与本地复验分开，不应声称已完成。

发布后的全新下载核对以交付时确认的远端提交为准；未改动用户原有技能、数据文件和其他仓库。
