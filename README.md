# QQQ / TQQQ 阶梯策略

用 QQQ 回撤信号逐档配置 TQQQ，并研究前高减半、移动退出和重新入场规则的 Python 策略项目。

本仓库是普通策略项目，不是 Agent Skill。保留用户提供的老虎量化原生代码，同时归档此前的 20 日前高研究版本、策略对比结果和迭代计划。

> **先分清版本：老虎源码使用 252 日最高收盘价、入场即启用 8% 退出；此前回测表使用 20 日日内最高价、前高减半后才启用退出。两者不是同一策略。研究结果不能当作当前老虎代码的收益。**

## 策略概述

基本思想：平时以 QQQ 为基础持仓；QQQ 从参考高点回撤时逐档配置 TQQQ；恢复前高时降低杠杆仓位；满足追踪退出条件后把资金转回 QQQ。

| QQQ 相对参考高点的回撤 | TQQQ 目标占比 | QQQ 目标占比 |
| --- | ---: | ---: |
| 尚未入场且不足 5% | 0% | 100% |
| 5% 至不足 10% | 10% | 90% |
| 10% 至不足 15% | 30% | 70% |
| 15% 至不足 20% | 40% | 60% |
| 20% 至不足 25% | 60% | 40% |
| 25% 至不足 30% | 65% | 35% |
| 30% 及以上 | 70% | 30% |

表中是策略目标。老虎执行版另乘 `INVESTED=0.995`、整数股取整并预留现金；目标 70% 不等于实际持仓硬上限。QQQ 与 TQQQ 之间切换并没有消除股票风险；账户不融资也不代表 TQQQ 没有内含杠杆。

| 项目 | `tiger-native-v2`：本次上传源码 | `research-20d-v1`：历史研究基准 |
| --- | --- | --- |
| 前高 | 最近 252 根历史日线最高**收盘价**，含最新信号日 | 信号日前 20 个交易日日内最高价，不含信号日 |
| 入场后参考 | `entry_high` 固定；`high` 可随新高上移 | 本轮入场前高固定 |
| 加仓 | 减半前按回撤档位提高目标；追踪退出优先 | 减半前按更深档位提高目标 |
| 减半条件 | 收盘达到入场前高的 99.5% | 收盘达到入场前高的 100% |
| 减半对象 | 当时计算得到的**目标权重**的一半 | 当时**实际 TQQQ 份额**的一半 |
| 8% 追踪 | **入场即启用**，减半前也会退出 | **减半后才启用** |
| 再入场 | 恢复锁定高点的 99.5%，或相对退出价再跌 `5% × 锁定高点` 后解锁 | 恢复退出时记录的峰值后解锁，再等新入场 |
| 调仓 | 每日尝试贴近目标，受挂单、现金、整数股约束 | 事件触发调仓，允许权重漂移 |
| 成交 | 平台原生撮合，先卖后买、现金约束限价买入 | 理想化下一交易日开盘、分数份额 |
| 已有收益证据 | 本仓库暂未收录该份代码的完整平台报告 | 下表与 `results/` 中的本地研究结果 |

## 成果展示：研究策略比较

这是 **20 日研究版** 的实际历史计算摘录，不是老虎原生代码报告。区间为 **2020-01-02 至 2026-10-16，1,707 个交易日**，初始 10 万美元；Yahoo Finance 拆分调整行情，分红以除息日收盘再投资近似；每一买卖腿按成交金额 0.1% 扣费；Sharpe 无风险利率为 0；回撤按每日收盘净值计算。2026 年是不完整年度。

| 策略 | CAGR | 最大回撤 | Sharpe | 期末资产（万美元） | 调仓次数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| **阶梯＋前高减半＋8%退出** | **25.98%** | **-45.67%** | **0.86** | **47.95** | **20** |
| 阶梯＋前高减半＋5%退出 | 26.59% | -45.67% | 0.88 | 49.53 | 23 |
| 阶梯＋前高全部退出 | 29.24% | -64.25% | 0.79 | 57.03 | 44 |
| 阶梯＋入场即8%退出 | 21.16% | -39.85% | 0.84 | 36.80 | 16 |
| 阶梯＋入场即5%退出 | 20.46% | -36.11% | 0.86 | 35.37 | 18 |
| 阶梯＋50日均线退出 | 19.92% | -35.40% | 0.85 | 34.32 | 12 |
| 阶梯＋175日均线下方2%退出 | 20.71% | -38.26% | 0.82 | 35.87 | 11 |
| 回撤档位对称减仓 | 21.25% | -43.14% | 0.78 | 36.98 | 61 |
| QQQ 买入持有 | 19.96% | -35.12% | 0.86 | 34.39 | 0 |
| TQQQ 买入持有 | 31.66% | -81.65% | 0.75 | 64.68 | 0 |

调仓次数不含初始建仓，不等于订单数；均线策略带入场过滤。除买入持有外，各比较策略沿用研究代码定义的周期锁定，不能把差异全部归因于退出阈值。其他起点、年度结果、概率实验和限制见 [完整报告](docs/backtests.md)。

这组结果支持“承担额外风险换取较高长期收益”，不支持“上涨和下跌都优于 QQQ”。研究基准的最大回撤发生于 2020 年；锁定机制让其 2023 年基本只持有 QQQ。旧本地 36.12% 和 QuantConnect 25.3% 摘要没有在本项目内完成逐笔复现，不作为本项目成绩。

## 使用老虎原生代码

1. 打开 [老虎量化](https://quant.itigerup.com/#backtest)，新建独立的 Python 回测策略。
2. 将 [完整源码](strategies/tiger/main.py) 粘贴到平台编辑器。平台注入 `symbol`、`order`、`data` 等对象，不要直接用普通 Python 执行该文件来代替平台回测。
3. 选择每日频率，基准 QQQ；研究对照可使用 100,000 USD 初始资金。源码正式起止是 **2020-01-03 至 2026-10-16**，与研究表的 2020-01-02 起点不同。
4. 页面区间和平台首次回调必须匹配源码。源码要求首次正式交易回调恰为 2020-01-03，并要求当时已有 252 根历史日线。平台初始化是否消耗一天需实际核对；不能通过删除日期检查来宣称通过。
5. 核对 `ACTUAL_START`、`SIGNAL`、`SIGNALS_COMPLETE`、订单状态、实际持仓和最终现金。末日不新下单，不强制清仓；`SIGNALS_COMPLETE` 不等于挂单全部成交。

买单限价为回调所见开盘价的 1.01 倍；卖单确认后才使用实际现金买入；现金预留至少 20 美元或净值的 0.5%。限价、未成交与分阶段调仓可能延后成交。代码 `set_slippage(0.0)` 不是零总成本声明，手续费仍需核对平台模型。

## 本地研究复现

Python 3.10+。先下载仓库并安装研究依赖：

```bash
git clone https://github.com/score2021/qqq-tqqq-ladder-strategy.git
cd qqq-tqqq-ladder-strategy
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

下面的样例会下载公开行情，写入被忽略的 `data/`，只运行本地研究，不连接券商、不下实盘订单：

```bash
python research/fetch_data.py --start 2012-01-01 --end 2026-10-16 --output data/market.json
python research/compare.py --data data/market.json --start 2020-01-02 --output runs/research-2020
```

输出 `summary.csv`、`summary.json`、`equity.csv`、`events.json`、`metadata.json`。研究数据下载自外部服务，可能限流或修订；失败应停止并检查数据，不用残缺行情替代。核对起止、行数、数据 SHA-256 和版本后比较结果。仓库只发布聚合结果，不分发原始行情。

## 后续迭代

### IBKR 小本金费用核实（2026-10-18）

用户提供的订单预览中，TQQQ 1 股和 1.2 股的预计佣金与费用均为 **0.35 USD**；QQQ 0.02 股（金额 14.56 USD）、TQQQ 0.2 股（金额 14.76 USD）均显示 **0.15 USD**。这笔混合订单没有额外叠加一份碎股手续费；小额纯碎股的约 1% 显示值也不能外推成每笔 100 USD 都收费 1 USD。

**仍待核实超过 35 USD 的纯碎股预览，尚未确定唯一完整费用函数。** 因此此前费用情景不作为账户实际费率结果，本文 2020 年起的成绩仍使用原有每买卖腿 0.1% 的成本假设。详见 [费用核实记录](docs/ibkr-fees.md)及[匿名化订单数据](results/ibkr-order-previews-2026-10-18.json)。

### 策略迭代

1. 先对齐老虎版与 20 日研究版，分别建立原生订单与研究净值基准。
2. 研究恢复前高前的风险约束；不能只靠减半后的 8% 退出控制急跌。
3. 比较峰值锁定、直接解锁和带反弹确认的再入场；直接取消锁定曾显著增加熊市损失。
4. 管理实际 TQQQ 权重与目标偏离，再比较减半比例、5%/8%退出及相邻参数。
5. 概率加仓暂作实验：深回撤案例很少，当前简单映射没有明确优于固定阶梯。

每次只改一个主要机制，报告收益、回撤、恢复期、敞口和成本，保留失败实验。详见 [迭代清单](docs/roadmap.md)。
